# Zoo Online

## Opis projektu

Zoo Online to prosta strona internetowa prezentująca informacje o zwierzętach. Projekt został wykonany w ramach zajęć z wykorzystaniem systemu kontroli wersji Git oraz platformy GitHub.

W ramach projektu dodano nową sekcję przedstawiającą zwierzę – pandę. Sekcja zawiera zdjęcie oraz krótki opis.

## Funkcjonalności

- wyświetlanie zdjęć zwierząt,
- przejrzysta struktura strony oparta o HTML,
- możliwość rozwijania projektu o kolejne gatunki zwierząt.

## Technologie

- HTML5
- Trello
- Git
- GitHub
