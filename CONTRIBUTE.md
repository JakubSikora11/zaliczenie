Dziękujemy za zainteresowanie rozwijaniem projektu Zoo Online.

## Zasady współpracy

### Tworzenie gałęzi

Każda nowa funkcjonalność lub poprawka powinna być wykonywana w osobnej gałęzi.

Format nazwy gałęzi: 

Zwierze

### Commity

Commity powinny być krótkie i opisowe.

Przykłady:
Dodano sekcję panda
Dodano zdjęcie pandy
Poprawiono strukturę HTML


### Pull Request

Przed połączeniem zmian z gałęzią główną należy utworzyć Pull Request zawierający:

- opis wprowadzonych zmian,
- informację o dodanych plikach,
- uzasadnienie wprowadzonych modyfikacji.

### Struktura plików

- zdjęcia zwierząt umieszczamy w katalogu `img`,
- pliki dokumentacji przechowujemy w głównym katalogu projektu,
- zachowujemy czytelną strukturę kodu HTML.

### Komunikacja

Wszelkie propozycje zmian oraz zgłaszanie błędów odbywa się za pośrednictwem GitHub Issues oraz Pull Requestów.

### Dobre praktyki

- stosuj czytelne nazwy plików,
- dbaj o poprawne wcięcia kodu,
- testuj zmiany przed wysłaniem do repozytorium,
- nie usuwaj istniejących funkcjonalności bez uzasadnienia.
